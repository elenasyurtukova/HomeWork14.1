# Проект 

## В проекте реализовано:
* в модуле category описан класс Category - категорий товаров, при этом 
атрибут списка товаров является приватным. 
* в модуле category реализованы: метод, возвращающий список товаров категории,
  метод, который выводит товары построчно, метод, добавляющий товар в список товаров,
  метод сложения стоимости всех товаров в категории.
* метод, добавляющий товар в список товаров, написан таким образом, что нет возможности
  добавить вместо продукта или его наследников любой другой объект.
* функциональность сложения написана таким образом, чтобы можно было складывать товары
  только из одинаковых классов продуктов, иначе выбрасывается ошибка TypeError
* в модуле product описан класс Product - товаров, при этом атрибут цены является приватным.
* в модуле product реализован метод изменения цены у товара
* в модуле product_iterator описан класс ProductIterator, который принимает на вход объект 
  класса категории и производит итерацию по товарам, которые хранятся в данной категории,
  т.е. метод выполнения следующего шага итерации возвращает очередной товар категории.
* в модуле utils реализована функция чтения из json-файла и функция, 
  которая создает объекты классов 'Категории' и 'Товары' из данных json-файла
* в модулях smartphone и lawngrass - Созданы два класса наследников класса Product
  Smartphone и LawnGrass с расширенными атрибутами.

## Установка:
1. Клонируйте репозиторий:
```git clone git@github.com:elenasyurtukova/HomeWork14.1.git```

2. Установите библиотеки из pyproject.toml:
```poetry install```

## Тесты:
Модули с описанием классов протестированы с помощью фреймворка pytest.
Чтобы запустить его (все тесты), выполните команду: ```pytest```.
